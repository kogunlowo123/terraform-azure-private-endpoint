# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-01

### Added

- Initial release of the Azure Private Endpoint Terraform module
- Private Endpoint creation with automatic and manual connection approval
- Private service connections to Azure PaaS resources and Private Link Services
- Multiple subresource support for various Azure services
- Private DNS Zone management with configurable SOA records
- DNS Zone virtual network links with auto-registration support
- Custom DNS A record management
- Private Link Service creation with NAT IP configuration
- Static IP assignment for private endpoints
- Custom network interface naming for private endpoints
- Support for resource ID and alias-based connections
- Cross-subscription and cross-tenant connectivity support
- Comprehensive tagging at all resource levels
- Comprehensive examples: basic, advanced, and complete
