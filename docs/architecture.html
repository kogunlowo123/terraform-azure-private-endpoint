Microsoft Azure Terraform Module Networking

terraform-azure-private-endpoint

Executive Summary

Production-ready Terraform module for deploying Azure Private Endpoints with comprehensive support for private DNS zones, DNS zone virtual network links, custom A records, Private Link Services with NAT IP configuration, static IP assignment, custom NIC naming, auto and manual connection approval workflows, and cross-subscription/cross-tenant connectivity. Serves as the foundational networking module for zero-trust Azure architectures.

1. Consumer resolves service FQDN via private DNS zone linked to VNet. 2. DNS returns private IP of the private endpoint NIC. 3. Traffic flows within the VNet through the private endpoint NIC. 4. Private service connection routes to the target PaaS resource or Private Link Service. 5. For PLS scenarios, NAT IP configuration maps to the load balancer backend.

Security Controls

Network Isolation

- All traffic stays within Azure backbone
- No public IP exposure for connected services
- Subnet-level placement of endpoint NICs
- Cross-subscription and cross-tenant support

Access Control

- Auto-approved connections (trusted resources)
- Manual approval workflows (external consumers)
- Visibility and auto-approval subscription lists
- Proxy protocol support for PLS

DNS Security

- Private DNS zones prevent DNS leakage
- VNet-linked zones for resolution scope
- Custom A records for override scenarios
- SOA record customization

IP Management

- Static IP assignment for private endpoints
- Custom NIC naming for governance
- NAT IP configuration for PLS
- IPv4 addressing support

Industry Adaptation

Enterprise Networking

Centralized private endpoint management for Storage, SQL, Key Vault, with DNS zones linked to hub VNet

Multi-Tenant SaaS

Private Link Services to expose SaaS backends, auto-approval for managed tenants, manual approval for external

Financial Services

Static IP endpoints for firewall allowlisting, cross-subscription connectivity, full DNS zone management

Government

Zero-trust networking with no public endpoints, private DNS for all PaaS services, audit via custom NIC naming

Production Readiness Checklist

  • Private DNS zones created for all target service types
  • DNS zones linked to consumer VNets
  • DNS zone groups configured on private endpoints
  • Validation: resource ID or alias specified for each endpoint
  • Link DNS zones to hub VNet for hub-spoke resolution
  • Configure static IPs for endpoints requiring firewall rules
  • Set up Private Link Services for internal service exposure
  • Review auto-approval subscription lists
  • Verify DNS resolution from consumer VNets

Deployment

terraform init
terraform plan -var-file="endpoints.tfvars"
terraform apply -var-file="endpoints.tfvars"

# Verify private endpoint
az network private-endpoint show --name pe-storage-blob --resource-group rg-myapp
# Check DNS resolution
az network private-dns zone show --name privatelink.blob.core.windows.net --resource-group rg-myapp
